# Bazi Theory Classical Corpus v1

`bazi-theory-classics-selected-v1` is the first reviewed classical-books baseline.
It contains selected high-value chapters, not complete editions, and is not yet production-approved.

| Work | Selected scope | Source status |
| --- | --- | --- |

| 神峰通考 | 病药说类 | Fixed Wikisource revision |
| 渊海子平 | 论日为主；论月令 | Fixed Wikisource revision |
| 子平真诠评注 | 论用神 | CTP URN snapshot; base edition unspecified |
| 三命通会 | 卷十·看命口诀 | Fixed Wikisource Siku Quanshu revision |

Every local source is pinned by SHA256. Classical wording and Marten interpretation are
separated by Markdown headings. Historical claims about wealth, rank, health, family, or
events remain source text and must not be promoted to verified real-world conclusions.

The corpus owner and reviewer remain unassigned; the repository owner remains the pending
final release approver. Licensed modern materials and future full-book expansions must enter
through the Knowledge Console with explicit license, provenance, review, and version metadata.
